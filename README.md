# HoverDict

把鼠标停在屏幕上的英文单词(或日语词)上,光标下方自动弹出**中文释义**并**朗读**——无需选中、无需复制。

因为取词主力是**屏幕 OCR**(而非 Accessibility API),所以对底层是 Web 渲染的应用同样有效:
Claude 桌面客户端、浏览器(Chrome/Edge/Safari)、VS Code 等。

> 状态:可用的早期版本。当前显示折叠后的中文释义并自动发音。

## 下载安装

👉 **[下载最新版 HoverDict.dmg](https://github.com/yizilian-iren/HoverDict/releases/latest)**(Apple 芯片 / macOS 14+)

### 第 1 步:安装
1. 双击下载好的 `HoverDict-0.3.dmg`
2. 在弹出的窗口里,把 **HoverDict** 图标拖到 **应用程序(Applications)** 文件夹

### 第 2 步:第一次打开(只需做一次)
未经苹果公证的软件,所以第一次打开系统会拦一下:

1. 打开 **应用程序** 文件夹,找到 **HoverDict**
2. **不要双击**,而是 **按住 Control 键点它**(或用触控板双指点),在菜单里选 **打开**
3. 弹出的提示框里再点一次 **打开**

> 如果上面没有「打开」按钮,或提示「已损坏」:
> 打开 **系统设置 → 隐私与安全性**,向下滚动,会看到一行「已阻止打开 HoverDict…」,
> 点它旁边的 **仍要打开**,再确认一次即可。

### 第 3 步:允许「屏幕录制」

1. 第一次运行会提示需要权限,点 **打开系统设置**
2. 在 **屏幕录制** 列表里把 **HoverDict** 的开关打开
3. 退出 HoverDict 再重新打开一次

### 完成 🎉
把鼠标停在任意英文单词上,下方就会弹出中文意思;多停一会儿会自动朗读。

## 功能

- 🖱️ **悬停取词**:光标静止约 0.2s 即触发,无需点击;延迟可在菜单栏「取词延迟」里调(即时 ~ 0.8s),会记住
- 👆 **点击取词**:菜单栏勾选「点击取词」后,只有点一下才弹释义,移动鼠标不再触发
- 🔤 **屏幕 OCR**:基于 Vision,适配 Electron/Chromium/WebKit 渲染的文字
- 🇨🇳 **中文释义**:优先用 macOS 自带的牛津英汉词典,每个义项前带语境提示(dismiss →「(reject) 对…不予考虑」);它没收的词(多为专业词、缩写)用内置的离线词库 [ECDICT](https://github.com/skywind3000/ECDICT)。含词形还原(running→run),并按上下文挑词性对应的释义(record 作动词还是名词)。
  牛津英汉需先在「词典」App → 设置里勾选 **简体中文 - 英语**;没勾选时全部用 ECDICT
- 🇯🇵 **日语取词**:停在含假名的日语上,显示「原形 读音」和中文释义(食べました→食べる【たべる】)。用的是 macOS 自带的日中辞典,需先在「词典」App → 设置里勾选 **简体中文 - 日语**;没启用时菜单项是灰的。可在菜单栏关闭
- 🙈 **少打扰**:数字、孤立的按钮文案(Send、OK)、the / is 这类基础词、Thinking 之类的状态文字不弹
- 🔊 **自动朗读**:停留约半秒后朗读,可在菜单栏「朗读发声」关闭
- 🪟 **不抢焦点**:非激活浮窗,阅读中的应用保持焦点;鼠标一动浮窗就淡出;全屏应用上也能显示
- 🎛️ **菜单栏控制**:暂停/继续(全局快捷键 **⌥⇧A**)、取词延迟、点击取词、日语取词、朗读发声、退出

### 关于联网

取词、OCR、查词都在本机完成。**只有朗读会联网**:一个词第一次被朗读时,这个词会发给 Google 翻译的语音接口取发音,之后缓存在本机
(`~/Library/Application Support/HoverDict/tts/`),再读就不联网了;没有网络时改用系统自带语音。
不想联网,在菜单栏关掉「朗读发声」即可。

## 系统要求

- macOS 14.0 (Sonoma) 及以上
- Apple 芯片(arm64)
- 仅需 **Command Line Tools**(无需完整 Xcode)即可从源码构建
